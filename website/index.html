03

Privacy

Local by design

Your listening history is not the product.

Roon discovery and playback monitoring stay on your machine and local network. There is no RRP account, no analytics pipeline, and no automatic diagnostic upload.

Install

Connect once. Let it run quietly.

macOS is the primary target; Windows and Linux are currently beta targets.

  1. 01
    Download a signed release

    Get the build for your platform from GitHub Releases when it is available.

  2. 02
    Enable the Roon extension

    Open Roon → Settings → Extensions, then enable Roon Rich Presence.

  3. 03
    Choose a playback zone

    Select one zone or follow whichever zone becomes active.

  4. 04
    Keep Discord open

    The desktop companion updates your activity while music is playing.
